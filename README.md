# DeepSeek ピークレーダー (Peak Radar)

DeepSeek API の価格2倍時間帯を iPhone Safari 上で直感的に確認できる、完全クライアントサイドの Web アプリです。

## 利用方法

1. GitHub Pages で HTTPS 公開された URL を iPhone Safari で開く
2. 共有メニュー →「ホーム画面に追加」で PWA としてインストール

## 仕様

### タイムゾーン
- 表示・内部判定はすべて **JST (Asia/Tokyo)** に固定
- 端末のタイムゾーン設定に依存しません

### デフォルトのピーク時間
| ピーク | 時間帯 (JST) |
|--------|-------------|
| ピーク① | 10:00 〜 13:00 |
| ピーク② | 15:00 〜 19:00 |

### 価格倍率
| 状態 | 倍率 |
|------|------|
| 営業日・ピーク時間中 | 2.0× |
| 営業日・ピーク時間外 | 1.0× |
| 土日（対象外） | 1.0× |
| 中国祝日（対象外） | 1.0× |

### 営業日設定
- 土日を価格2倍の対象外にする（デフォルト: ON）
- 中国祝日を価格2倍の対象外にする（デフォルト: ON）
- 中国の振替出勤日を営業日として扱う（デフォルト: ON）

### 設定の保存
- 設定は `localStorage` に保存され、ページ再読み込み後も維持されます

### オフライン動作
- 中国営業日カレンダーは内蔵（外部通信不要）
- Service Worker による静的ファイルのキャッシュ

## 設定項目

⚙ ボタンから設定画面を開き、以下を変更できます：
- ピーク①・②の開始/終了時刻（0〜23の整数）
- 土日除外 / 中国祝日除外 / 振替出勤日扱いの ON/OFF

## 既知の制限

- 中国営業日カレンダーは 2026 年のみ内蔵。未登録年度は通常の曜日判定へフォールバックし、「祝日データ未登録」と表示します
- iPhone 実機での動作は未確認です
